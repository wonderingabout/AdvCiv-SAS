# Legacy and reference material

This tree contains inherited or pre-AdvCiv-SAS documentation and visual reference material. It is kept for source archaeology, comparison, troubleshooting, and LLM/code-agent review rather than as current AdvCiv-SAS documentation.

The top-level `Docs/` and `Images/` split intentionally mirrors [`_1_AdvCiv-SAS/`](/_1_AdvCiv-SAS/) where that makes comparisons easier.

## Docs

- `AdvCiv/` contains the inherited base-AdvCiv manual and related reference files.
- `BBAI/` contains Better BTS AI documentation, including its changelog and notes; the upstream code/history is available from [the Civ4 Better AI SourceForge project](https://sourceforge.net/p/civ4betterai/code/HEAD/tree/).
- `BUG/` contains inherited BUG documentation and local help files used by AdvCiv-SAS.
- `Civ4BUG_Python_API/` contains a local plain-text copy of the [Civ4 BUG Python API reference](https://civ4bug.sourceforge.net/PythonAPI/). The old SourceForge-derived folder/file names were shortened because their provenance is documented here and the extra repetition was not useful; the `_web` suffix in `all_classes_web.txt` marks content copied from the web rather than written for this repository.
- `K-Mod/` contains inherited K-Mod documentation.
- `git_logs/` contains anonymized K-Mod and pre-SAS AdvCiv Git history used by the source-history tooling.

Imported material remains subject to its original rights and provenance; moving or renaming a local reference file does not make it AdvCiv-SAS-original work.

## Images

[`Images/`](/_0_Legacy/Images/) contains legacy base-AdvCiv UI screenshots organized under the same broad category names used by the current AdvCiv-SAS image tree when practical.

These are comparison/reference screenshots, not current AdvCiv-SAS UI documentation. See the [image notes](/_0_Legacy/Images/README.md) for version, numbering and usage context.
